# ECMAScript Code Samples (es-samples)

A comprehensive collection of executable code samples representing new language features added in each edition of ECMAScript (ES2011/ES5.1 to ES2026).

## Usage

```javascript
import * as esSamples from 'es-samples';
// or
import * as es2015 from 'es-samples/samples/es2015';
```

## Testing

Run tests to verify sample code validity:

```bash
npm test
```
